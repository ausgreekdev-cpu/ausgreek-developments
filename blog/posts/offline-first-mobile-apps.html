Building offline-first mobile apps for WA mine sites

Internet connectivity on WA mine sites is notoriously poor. Standard web apps stop working the moment the signal drops. Here's how we build apps that keep field teams productive.

The problem

RC, diamond, and air-core drill rigs operate in dead zones. Paper dockets get lost, data gets re-keyed, and stock counts go stale. Off-the-shelf tools like ServiceM8 assume a connection.

The approach: SQLite + sync

We use React Native with a local SQLite database. Every action is written locally first, then synced to the cloud when connectivity returns. Conflict resolution handles concurrent edits.

// Write locally, sync when online
const db = new SQLite();
await db.insert(job);
if (navigator.onLine) {
  await sync.toServer();
}

Key decisions

  • Local-first writes: never block the user on a network request.
  • Conflict resolution: last-write-wins with audit log, or merge strategies per field.
  • Background sync: queue changes and retry with exponential backoff.
  • Multi-tenant: role-based access for crews, supervisors, office.

Results

Field teams capture data without waiting on a signal. Office sees real-time status when connected. Zero lost dockets.
